Coarse-grained simulation

AlphaFold’s model of thioredoxin 1 from E. coli, whose N-terminal strand threads one of its own loops.

Simulated from AlphaFold DB model AF-P0AA25-F1, CC BY 4.0.

The menu above the protein switches between four proteins. With the protein focused, the arrow keys turn it. The Heat switch melts it and turning it off lets it fold back. Colours follow AlphaFold’s confidence scale and show how much of each part’s native structure is in place.

Why I built it

At NCEMS I map entanglements, where a protein’s chain threads one of its own loops, across 555,846 AlphaFold structures. That work got me into protein misfolding. A folding chain can thread the wrong loop and get stuck, because escaping means partly unfolding first. Nothing here is scripted. Melt a protein, let it cool, and it finds its own way back, or gets stuck the same way.

Ferrite

A Redis-compatible in-memory database in C++20.

  • 6,500 lines of dependency-free C++20, with thread-per-core epoll workers over a 256-shard keyspace, Robin Hood hashing, skip-list sorted sets, snapshots and 128 Redis commands. Ordered locking keeps multi-key transactions atomic and deadlock-free.
  • Benchmarked against Redis 7.0 on one core each, it matches Redis without pipelining and reaches 1.31 times its throughput at depth 16, 1.83 times on GET at depth 256 and 3.7 times lower p99 latency on large reads, by answering each batch with one write.
  • Checked reply-for-reply against real Redis on 6,000 random commands, and clean under AddressSanitizer, UndefinedBehaviorSanitizer and ThreadSanitizer.
  • With a client that never reads its replies, memory stayed at 71 MiB while Redis grew to 416 MiB.

  2. Name That LLM Kaggle

    Running to Jan 2027

    Work out which of 18 language models wrote a passage.

    • Set up cross-validation grouped by prompt first, so a model is never scored on a prompt it has already seen, and a word and character TF-IDF classifier as the baseline to beat.
    • Tried grouping passages by prompt and assigning labels across the group as a matching problem. It helped in cross-validation but not on the leaderboard, so I dropped it.
    • The approach I kept reads mid-layer embeddings out of a frozen open base model and fits a linear classifier on them, blended with the TF-IDF and writing-style features at weights fitted out of fold.
    • Chose the layer and the model size by probing both on my own machine, and used a learning curve to see how much more labelled data would be worth.

    Method only while the competition is open.

  3. Squares in Squares Kaggle

    Running

    Pack n unit squares, free to rotate, into the smallest containing square, for every n up to 1,000.

    • Started with a local scorer: an exact overlap test for rotated squares, plus a safety margin, so a layout is only submitted once it is provably legal.
    • Small n is a lookup problem, so the plan is to seed from the published best-known packings and check each one against the border and monotonicity rules.
    • Large n is a construction problem, so parameterized strip and tilted-band layouts generate a starting point, which an inflation optimizer and an evolutionary search then tighten.
    • The plain grid packing is the baseline each n has to beat.

    Method only while the competition is open.

  4. NFL Big Data Bowl 2027 Kaggle

    Writeup due Jan 6

    An open analytics question on the new Combine tracking data, judged as a written report.

    • Framed it as whether Combine tracking measures carry information about NFL play, and started with offensive line pass protection, where the on-field measure is cleanest.
    • Audited the data first and measured how repeatable each NFL metric is across a split half of the season, so an effect is only pursued where the measure is stable enough to find one.
    • Registered each hypothesis with its test and its failure rule before running it, and dropped the first one when it failed its own rule.
    • Validated the pipeline on synthetic seasons with known effects planted in them, and controlled the false discovery rate across the tests. Written in Polars with bootstrap intervals throughout.

    Findings stay in the report until it is submitted.

  5. Biohub Cell Tracking Kaggle

    Summer 2026

    Follow dividing cells through microscopy video, scored on both the links between frames and the divisions.

    • Built a local validation harness around the competition's own scorer, so every change could be measured before it cost a submission.
    • Split the score by error type, which showed finding the cells was already solved at 0.99 recall and all the remaining loss sat in linking them between frames. That moved the work off detection entirely.
    • Swept the minimum track length and calibrated the gap between my local score and the leaderboard, which took the leaderboard score from 0.861 to 0.882.
    • Identified the smoothing step that the top public solutions shared, by fitting a line through each cell's neighbouring frames, as the next thing to add.
